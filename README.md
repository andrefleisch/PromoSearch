# PromoSearch

Marketplace de promoções com busca por geolocalização - lojas publicam ofertas, 
clientes buscam no mapa e salvam as que interessam. Desenvolvido em grupo, como 
projeto multidisciplinar (Experiência Criativa, Desenvolvimento Web, Engenharia de 
Requisitos e Banco de Dados), ao longo de um semestre a partir de junho de 2025.

## Equipe

André Gustavo, Babbingtonn Luiz, Eduardo Michelin

## Meu papel

Banco de dados, CRUDs e o mapa de busca (geolocalização), entre outras funcionalidades.

## Funcionalidades

- Três perfis de usuário: cliente, loja e administrador, cada um com painel próprio
- Cadastro, login, recuperação de senha, edição de perfil
- Lojas cadastram e gerenciam produtos e promoções (criar, editar, remover, publicar)
- Clientes buscam promoções por mapa e salvam as de interesse
- Sistema de denúncias com fluxo completo: registrar, resolver, histórico de penalizações

## Tecnologias

PHP, Composer
